# LabJack Workflows

This directory contains Bonsai workflows for data acquisition with **LabJack** DAQ devices (`Bonsai.LabJack`).

## Workflow Categories

### 1. Multi-Channel Analog Input Acquisition
- **`testAIN.bonsai`**: Configures a LabJack `AnalogInput` source to stream multi-channel analog scans (`AIN0`, `AIN1`) at a specified scan block size (`ScansPerRead`).
