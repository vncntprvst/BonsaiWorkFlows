# Basler Pylon Camera Settings (`.pfs`)

This directory stores **Basler Pylon Viewer** feature stream (`.pfs`) configuration files loaded by `Bonsai.Pylon.PylonCapture` nodes.

## Configuration Profiles

- **`acA640-750um_triggered500Hz.pfs` / `acA640-750um_triggered500Hz_318rig.pfs` / `acA640-750um_trig500Hz_400usExp_f8_335rig.pfs`**: 500 Hz hardware-triggered high-speed whisker tracking profiles for the Basler acA640-750um camera.
- **`acA720-520um_default.pfs` / `acA720-520um_triggered.pfs` / `acA720-520um_40030319_triggered100Hz_Exp5ms.pfs`**: Free-running and 100 Hz hardware-triggered profiles for the Basler acA720-520um camera.
- **`acA1920-155um_default.pfs`**: Default acquisition profile for the Basler acA1920-155um camera.
